# Hercules Admin Web

React + TypeScript + Vite 管理台，采用明亮、低饱和视觉体系，包含响应式桌面与移动布局。

## 页面

- 登录与注册（注册时按完整组织名称或组织 ID 精确搜索）
- 运营概览
- 组织树 CRUD
- 用户 CRUD、组织/角色/直接权限分配
- 角色 CRUD 与角色权限分配
- 权限 CRUD
- 个人资料、角色和权限查看

新建组织、用户和角色时无需输入业务 ID。组织名称、用户名、所属组织、角色名称、权限名称及权限
编码在表单中用 `*` 标识并进行前端必填校验。管理员创建用户时可留空密码，由后端生成一次性初始
密码；结果弹窗默认使用 `*` 遮挡，并支持点击查看。权限编码提示与校验采用 `report.read` 格式。

## 开发

```bash
npm install
npm run dev
```

开发服务为 `http://127.0.0.1:5173`，`/api` 自动代理到 `http://127.0.0.1:8000`。

## 生产构建

```bash
npm run build
```

产物位于 `dist/`。生产部署时应由 Web 服务器托管静态文件，并将 `/api` 反向代理到后端服务。

项目根目录的 `docker-compose.yaml` 会构建本目录的多阶段 Dockerfile，最终由 Nginx 提供静态文件并将 `/api` 代理到 `admin:8000`。可使用 `./scripts/run.sh start` 与其他服务统一启动。
